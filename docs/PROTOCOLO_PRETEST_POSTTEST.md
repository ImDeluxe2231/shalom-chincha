# Protocolo de aplicación del pretest y postest

## 1. Preparación

1. Confirmar la autorización de la empresa y el consentimiento de los 15
   trabajadores.
2. Asignar códigos P01 a P15 y conservar la correspondencia, si fuera necesaria,
   fuera del sistema y bajo custodia de los investigadores.
3. Confirmar con la asesora el número de días y operaciones observadas.
4. Separar una base demostrativa de la base que se utilizará en la investigación.

## 2. Pretest

1. Observar el proceso vigente antes de introducir el sistema como tratamiento.
2. Completar la ficha de trazabilidad durante los días establecidos.
3. Cronometrar consultas y actualizaciones según el Anexo 3.
4. Aplicar el cuestionario de diez ítems a los 15 trabajadores.
5. Digitalizar las fichas en el Módulo 7 seleccionando `Pretest`.
6. Exportar el primer respaldo y conservar las fichas físicas originales.

## 3. Intervención

1. Capacitar al personal por perfil: administrador, administrativo y operativo.
2. Realizar una prueba de aceptación con casos controlados.
3. Habilitar el uso del sistema durante el periodo aprobado.
4. Registrar incidencias de adopción, interrupciones de internet y cambios de
   procedimiento que puedan influir en los resultados.

## 4. Postest

1. Repetir las fichas con el mismo criterio, horarios y cantidad de observaciones.
2. Aplicar el mismo cuestionario a los mismos códigos P01 a P15.
3. Digitalizar los datos seleccionando `Postest`.
4. Revisar que cada participante tenga como máximo un cuestionario por fase.
5. Exportar la base para SPSS y crear un respaldo del sistema.

## 5. Análisis

El centro de validación ofrece comparaciones descriptivas. La contrastación de
hipótesis debe realizarse en SPSS después de evaluar normalidad y seleccionar
la prueba para muestras relacionadas que corresponda. La elección de la prueba
debe documentarse con la asesora; el sistema no declara significancia
estadística por sí solo.

## 6. Evidencias para sustentación

- autorización de Shalom Chincha;
- consentimientos informados;
- instrumentos validados;
- fichas originales del pretest y postest;
- captura del centro de validación;
- archivo exportado para SPSS;
- archivo de datos y salida de SPSS;
- pruebas de aceptación firmadas;
- manual de usuario y manual técnico;
- evidencia de publicación con HTTPS;
- respaldo verificable.
